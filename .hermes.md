## 🏗️ Architecture

```
donis_finance/
├── sub_app/webapp/          ← Frontend (Vite + React + Tailwind + TypeScript)
│   ├── src/
│   │   ├── api/index.ts     ← API service (typed fetch wrapper)
│   │   ├── components/      ← AuthLayout, DashboardLayout, AdminLayout, Modal, Drawer, Pagination, LanguageSwitcher, ExpenseChart, IncomeVsExpenseChart (.tsx)
│   │   ├── context/         ← AuthContext, ThemeContext (.tsx)
│   │   ├── i18n/            ← config.ts, id.json, en.json
│   │   └── pages/
│   │       ├── admin/       ← Admin pages + Admin Login (.tsx)
│   │       └── member/      ← Member pages (.tsx)
│   ├── tsconfig.json        ← TypeScript strict config
│   ├── vite.config.ts       ← Dev server (port 8202, proxy /api → 8200)
│   └── dist/                ← Build output
├── templates/index.tmpl     ← Go template (copas dari dist/index.html)
├── plugins/donisfinance/    ← Go plugin
│   ├── handlers/            ← HTTP handlers
│   ├── services/            ← Business logic
│   ├── models/              ← GORM models
│   └── console/             ← CLI commands
└── internal/app/            ← Core framework
    └── bootstrap.go         ← Route registration, CORS, SPA static serving
```

## 🚀 Dev Workflow

```bash
# 1. Backend (Go API) — port 8200
cd ~/workspaces/donis_finance
./run.sh                        # build + start

# 2. Frontend (Vite dev + TypeScript) — port 8202
cd sub_app/webapp
npm run dev                     # HMR, proxy API ke 8200
npx tsc --noEmit                # Cek TypeScript errors (opsional)
npx vite build                  # Build production (type-checked via tsconfig)

# 3. Akses
http://100.104.55.66:8200       # Production (Go serve)
http://100.104.55.66:8202       # Development (Vite HMR)

# 4. Build production
npm run build                   # → dist/
# copas index.html → templates/index.tmpl
# update asset filenames
# restart Go server
```
